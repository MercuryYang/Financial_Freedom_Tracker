# 验收记录

本记录对应 `CONSTRUCTION.md` 第 11 节。API 自动化、浏览器交互和 Docker 部署分别验收；一类检查通过不代表其他检查通过。

## 隔离 API 验收

测试文件：`backend/tests/test_acceptance.py`。每个用例创建独立临时 SQLite 文件，注入固定日期和模拟汇率，不访问在线汇率服务，不读取或修改日常记账数据。

从项目根目录运行：

```sh
cd backend
.venv/bin/python -m pytest tests/test_acceptance.py -q
```

覆盖范围：

| 施工验收项 | API 检查 |
| --- | --- |
| 多币种收入 | 原始 USD 金额保留；列表、月度汇总与 Dashboard 折算一致 |
| 周期收支 | 31 日规则在 2 月落至月末；重复读取不重复记账；停用不生成；恢复和删除规则保留历史 |
| 分类预算 | 当月多币种支出折算；超预算标记；其他月份不混入；取消预算保留实际支出 |
| 存款目标 | 两币种存入累计、剩余金额、进度；删除贡献与删除目标 |
| 净资产 | 账户与投资统一计入且无重复；同日快照覆盖；删除最后资产后真实余额归零 |
| Dream 购买 | 实付金额覆盖默认价格；生成购物支出；重复及并发购买只记一笔；状态更新不能绕过购买记账 |
| 投资 | 含费均价、卖出已实现盈亏、并发卖出防超卖、清仓成本归零、重新建仓、小数份额清仓与估值联动 |
| 汇率离线 | 无缓存时 CNY 可用、外币写入失败并回滚；旧缓存跨应用重开保留，返回更新时间与过期标记 |
| 输入校验 | 负数、零、NaN、Infinity、错误币种、收支分类不匹配与非法日期被拒绝 |

### 行为约定

- 周期规则恢复后，依据 `last_generated` 游标补齐尚未生成月份，包括停用期间；停用期间访问页面不会生成记录。此行为与当前游标补记方案一致。
- 初始空数据库不生成净资产零点；曾经存在资产后归零会记录零余额，避免历史趋势仍显示已删除的资产余额。
- Dream 从已购改回待购会清空购买日期，但不自动删除历史支出；用户需按施工文档手动删除对应支出后重新购买。

### 本轮 API 结果

2026-11-18：独立验收集 **22 passed**（0.63 秒）。首次执行发现“首次失败请求回滚汇率缓存后，节流状态阻止下一笔有效外币交易”的问题；后端修复后，针对性回归及完整验收集均通过。

另对 `0000-01`、`9999-12` 月份参数实际探测：收支列表、月度汇总和预算接口均返回 422；输入上限数量与价格的持仓创建未触发服务器错误。

环境存在一项 Starlette 对测试客户端 `httpx` 的弃用警告，不影响本轮测试结果。此处结果仅覆盖 API；页面视觉、浏览器交互和 Docker 结果见下节。
